# ADMIN-ELECRONLEARNING

Administration Console for the electrON Learning Platform.

## Features
- **Video Content Management**: Support for YouTube, Google Drive, Vimeo, and direct MP4 lectures.
- **Scheduled Live Streams & Premieres**: Broadcast live sessions or schedule future premieres with live countdowns.
- **Subject Categories & Unit Playlists**: Structure courses into organized units and modular syllabi.
- **Study Materials Integration**: Attach PDF notes, slides, and reference links to each lesson.
- **Responsive Mobile & Desktop Console**: Dedicated mobile-optimized navigation, touch-friendly cards, and cinema preview players.

## Tech Stack
- React 19 + TypeScript
- Vite
- Firebase Firestore & Storage
- Lucide React Icons
